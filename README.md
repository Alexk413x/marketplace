# Alex Koch's Claude Code plugins

Claude Code plugins that each work on their own and work better together.

## Install

Add the marketplace once:

```sh
claude plugin marketplace add Alexk413x/marketplace
```

Then install any plugin by name:

```sh
claude plugin install the-index@alexk413x
```

## Plugins

| Plugin | What it does |
|---|---|
| [The Index](https://github.com/Alexk413x/the-index) | A band above the prompt that shows session cost, limits and git state. |

Each plugin has its own licence in its repository.
